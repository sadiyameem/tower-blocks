# Tower Blocks

# Description
- This is a stacking game where the player will build a tower by stopping the moving blocks. Each block moves back and forth to give the player a chance to place there block.

# Features
- Moving blocks
- Stacking block
- Score counter
- Button that changes the background color

# Tools used
- HTML
- CSS
- JavaScript

# Challenges/Learned
- One challenge was getting the blocks to stack and appear the same size and shape.
- I learned how to use animations and other sizing elements.
